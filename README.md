# Backend Developer Portfolio

화이트·민트 색감의 반응형 정적 포트폴리오입니다. GitHub Pages에서 빌드 없이 동작합니다.

## 미리보기

`index.html`을 브라우저에서 열거나 `node preview.cjs`를 실행한 뒤 http://127.0.0.1:8123 에 접속합니다.

## 수정 위치

- `project-data.js`: 네 프로젝트의 개요, 역할, 성과, 트러블슈팅, 이미지 경로를 한 곳에서 편집합니다.
- `app.js`: 테마, 프로젝트 선택, 상세 창, 이미지 확대 보기, 연락처 동작. 맨 위 `profile.name`에 실제 이름을 넣습니다.
- `site.css`: 화면별 구분 주석이 있는 통합 스타일. 마지막 가독성 규칙은 공통 글씨·버튼과 모바일 대응을 조정합니다.
- `index.html`: 첫 화면, 카드 목록, About, 교육·자격, 연락처. 카드의 요약을 바꿀 때는 여기에서도 수정합니다.
- `assets/`: 썸네일, 아키텍처, ERD, About 그림.
- `about-section.html`, `experience-section.html`: 작성 과정의 섹션 참고본입니다. 실제 페이지는 `index.html`이므로 변경은 실제 페이지에도 반영하세요.

## 동작

카드 클릭 또는 카드에 포커스한 뒤 Enter/Space는 카드를 선택합니다. 좌우 키, 스와이프, 이전·다음 버튼으로 이동하고 ‘상세 보기’로 엽니다. 상세 목차 전환 시 새 내용으로 포커스가 이동합니다. 닫기 버튼이나 Escape로 닫으면 열었던 버튼으로 돌아갑니다.

아키텍처·ERD·하드웨어 사진은 페이지 내 이미지 뷰어에서 확대할 수 있습니다. 확대 후 스크롤로 이동하고 ‘맞춤’으로 초기화합니다. PC 상세 창은 같은 크기를 유지하며 모바일에서는 높이를 유연하게 조정합니다.

라이트·다크 모드와 모션 감소 설정을 지원합니다. Google Fonts 연결이 불가능하면 시스템 글꼴로 표시합니다. About의 성능 지표 그림은 설명용 예시입니다.

## 확인

```sh
node --check app.js
node --check project-data.js
node verify.cjs
```

검사는 프로젝트 데이터, 이미지 및 파일 경로, 중복 ID를 확인합니다. 실제 모바일 화면, 브라우저 확대, 키보드 동작은 브라우저에서 별도로 확인해야 합니다.

## GitHub Pages

1. GitHub 저장소에 이 폴더의 사이트 파일을 업로드합니다.
2. Settings → Pages에서 Deploy from a branch를 선택합니다.
3. 배포 브랜치와 /(root)를 지정합니다.
4. Pages에 표시되는 배포 주소로 접속합니다.

`.nojekyll`과 상대 경로를 사용하므로 저장소 하위 주소에도 대응합니다. API 키나 서버는 필요하지 않습니다.
